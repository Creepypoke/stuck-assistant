# Регрессии Dino Crisis

20 существующих вопросов и ожидаемых фактов из локального исходника Dino Crisis.
В P0 добавлены document ID и SHA256 текста к ранее выбранным sequence, чтобы
выявлять устаревший эталон и использовать те же фрагменты в oracle-context.
Это проверка соответствия прохождению, не независимая проверка сведений об игре.

Исторические измерения FTS/4B: [reports](../reports/FTS-COMPARISON-REPORT.md).
